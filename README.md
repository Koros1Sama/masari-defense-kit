# 🎓 Masari — Software Engineering Defense Kit

حقيبة مناقشة مشروع التخرج **«مساري — نظام التنقل الذكي في مدينة صنعاء»** لمقرر هندسة البرمجيات.

## المستويات
| الصفحة | المحتوى |
|:--|:--|
| `index.html` | الفهرس + خطة مذاكرة ليلة المناقشة |
| `summary.html` | ملخص سريع: نصوص إلقاء + الفصول السبعة + 34 رقمًا ذهبيًا + توزيع الأدوار |
| `page-by-page.html` | شرح كل صفحة من صفحات الوثيقة الـ 56 (مدمجة كصور) |
| `diagrams.html` | المخططات التسع بالتفصيل الكامل |
| `lessons.html` | 17 محاضرة من المنهج مشروحة ومرتبطة بالمشروع |
| `questions.html` | 63 سؤال مناقشة بإجابات + بحث وتصفية |
